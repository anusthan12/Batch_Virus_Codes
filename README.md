## ⚠️ Disclaimer

This repository is intended **strictly for educational and ethical learning purposes**. It demonstrates concepts that highlight why modern system security exists and how it protects users. Nothing here promotes or facilitates harmful or unauthorized use of any system.

---

## 📌 Overview

This repository represents an early-stage exploration into Windows batch scripting and system-level behavior — studying how simple scripts can:

- Interact with operating system processes
- Trigger system-level commands
- Simulate misuse scenarios to study system resilience and security responses

---

## 🎯 Objectives

- Understand low-level system interactions using batch scripting
- Explore how misuse of scripts can impact system performance
- Learn the importance of system protections (permissions, UAC, recovery tools)
- Build a foundation for cybersecurity awareness and defensive thinking

---

## 🧪 Project Modules

| Module | Description |
| :--- | :--- |
| **🔁 Infinite Loops** | Simulates CPU/resource exhaustion scenarios |
| **⚡ Shutdown Scripts** | Demonstrates system command execution |
| **📂 File Operations** | Explores file manipulation behaviors |
| **💥 Crash Simulation** | Tests system response to stress conditions |
| **🎲 Russian Roulette Script** | Randomized execution logic experiment |

---

## 🧠 Key Learnings

Modern operating systems are highly secure and resilient. Working through these experiments reinforced why:

- Many scripts fail gracefully due to permission restrictions, security layers, and system recovery mechanisms
- Even simple batch scripts demonstrate in concrete terms why cybersecurity fundamentals matter
- Defensive thinking starts with understanding the offensive surface
